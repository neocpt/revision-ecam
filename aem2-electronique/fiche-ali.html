Fiche : les montages à ALI à connaître

Tous les montages à ALI des chapitres 3, 4, 5 et 6 : nom, schéma et formules. Rien n’est affiché au départ : à toi de retrouver le reste.

Comment t’en servir
  1. Chaque montage a trois parties : Nom, Montage (schéma) et Formules. Elles sont toutes masquées au départ.
  2. Clique sur une partie pour l’afficher. Ou utilise les boutons ci-dessous pour n’afficher que les noms, que les schémas ou que les formules.
  3. Pour t’entraîner : à partir d’un schéma, retrouve le nom, puis les formules, puis refais le raisonnement sur papier.

1. Régime linéaire (ch3, ch6)

Rétroaction négative sur la borne −. Ici ε = 0, donc V+ = V−.

1linéaire

Montage suiveur

  • \[ V_s = V_e \]
  • \[ \underline H = 1 \]
  • Ze = ∞ ; Zs = 0 (adaptateur d’impédance)
2linéaire

Amplificateur inverseur

  • \[ V_s = -\dfrac{R_2}{R_1}\,V_e \]
  • \[ \underline H = -\dfrac{R_2}{R_1} \]
  • Ze = R1 ; déphasage de 180°
3linéaire

Amplificateur non inverseur

  • \[ V_s = \left(1+\dfrac{R_2}{R_1}\right)V_e \]
  • Ze = ∞ ; gain toujours ≥ 1
4linéaire

Intégrateur (inverseur)

  • \[ V_s(t) = -\dfrac{1}{RC}\displaystyle\int V_e\,dt \]
  • \[ \underline H = -\dfrac{1}{jRC\omega} \]
  • \[ |\underline H| = \dfrac{1}{RC\omega} \]
  • pente −20 dB/décade ; phase +90°
5linéaire

Pseudo-intégrateur

  • \[ \underline H = -\dfrac{R'/R}{1+jR'C\omega} \]
  • \[ \text{gain statique} = -\dfrac{R'}{R} \]
  • \[ f_c = \dfrac{1}{2\pi R'C} \]
6linéaire

Dérivateur (inverseur)

  • \[ V_s = -RC\,\dfrac{dV_e}{dt} \]
  • \[ \underline H = -jRC\omega \]
  • \[ |\underline H| = RC\omega \]
  • pente +20 dB/décade ; phase −90°
7linéaire (CNA, ch6)

Sommateur inverseur pondéré (CNA)

  • \[ V_s = -R'\sum_k \dfrac{V_k}{R_k} \]
  • \[ R_n = \dfrac{R}{2^n}\ \Rightarrow\ V_s = -\dfrac{R'E}{R}\sum_n K_n 2^n = -q\,N \]
  • \[ q = \dfrac{R'E}{R}\ \text{(pas de conversion)} \]
  • Masse virtuelle : chaque branche débite E/R_k

2. Régime saturé (ch4)

Pas de rétroaction sur la borne − : la sortie vaut ±V_sat.

8saturé

Comparateur simple

  • \[ V_s = +V_{sat}\ \text{si}\ V_e > E_0 \]
  • \[ V_s = -V_{sat}\ \text{si}\ V_e < E_0 \]
  • aucune rétroaction : ALI saturé
9saturé (hystérésis)

Comparateur à hystérésis, seuil E0 non symétrique

  • \[ \varepsilon = \dfrac{R_2V_e+R_1V_s}{R_1+R_2}-E_0 \]
  • \[ V_{seuil\,haut} = \left(1+\dfrac{R_1}{R_2}\right)E_0 + \dfrac{R_1}{R_2}V_{sat} \]
  • \[ V_{seuil\,bas} = \left(1+\dfrac{R_1}{R_2}\right)E_0 - \dfrac{R_1}{R_2}V_{sat} \]
10saturé (hystérésis)

Trigger de Schmitt non inverseur

  • \[ \varepsilon = \dfrac{R_2V_e+R_1V_s}{R_1+R_2} \]
  • \[ V_{seuil} = \pm\dfrac{R_1}{R_2}V_{sat} \]
  • \[ \text{largeur d’hystérésis} = 2\dfrac{R_1}{R_2}V_{sat} \]
  • retour de V_s sur la borne + : réaction positive
11saturé (hystérésis)

Trigger de Schmitt inverseur

  • \[ V_+ = \dfrac{R_1}{R_1+R_2}\,V_s \]
  • \[ V_{seuil} = \pm\dfrac{R_1}{R_1+R_2}\,V_{sat} \]
  • V_s passe à −V_sat quand V_e dépasse le seuil haut : sortie inversée

3. Oscillateurs (ch5)

Multivibrateurs (ALI saturé) et oscillateur quasi-sinusoïdal (ALI linéaire).

12oscillateur (saturé)

Multivibrateur astable compact (comparateur + RC)

  • \[ \alpha = \dfrac{R_1}{R_1+R_2} \]
  • \[ RC\,\dfrac{du_1}{dt}+u_1 = u_2 \]
  • \[ T = 2RC\ln\dfrac{1+\alpha}{1-\alpha} \]
  • si α ≪ 1 : T ≈ 4αRC ; rapport cyclique 50 %
13oscillateur (relaxation)

Multivibrateur astable à 2 ALI (MVA du TP5a)

  • \[ V_1 : \text{créneau } \pm V_{sat}\ ;\ V_2 : \text{triangle } \pm\dfrac{R_1}{R_2}V_{sat} \]
  • \[ T = \dfrac{4\,R_1R_3C}{R_2} \]
  • R3 = résistance d’entrée de l’intégrateur ; T indépendante de V_sat
14oscillateur (linéaire)

Oscillateur de Wien (quasi-sinusoïdal)

  • \[ \underline\beta = \dfrac{1/3}{1+\dfrac{j}{3}\left(\dfrac{\omega}{\omega_0}-\dfrac{\omega_0}{\omega}\right)} \]
  • \[ \omega_0 = \dfrac{1}{RC}\ ,\quad \underline\beta(\omega_0)=\dfrac13 \]
  • \[ A = 1+\dfrac{R_2}{R_1}\ \text{et}\ A\,\underline\beta(\omega_0)=1 \Rightarrow R_2 = 2R_1 \]
  • \[ T_0 = 2\pi RC \]
