Fiche : filtres du 1er et du 2e ordre (RC, RL, RLC)

Les filtres passifs du chapitre 1 : nom, schéma et formules. Rien n’est affiché au départ : choisis ce que tu veux revoir.

Comment t’en servir
  1. Chaque montage a trois parties : Nom, Montage (schéma) et Formules. Elles sont toutes masquées au départ.
  2. Clique sur une partie pour l’afficher. Ou utilise les boutons ci-dessous pour n’afficher que les noms, que les schémas ou que les formules.
  3. Pour t’entraîner : à partir d’un schéma, retrouve le nom, puis les formules, puis refais le raisonnement sur papier.

1. Filtres du 1er ordre RC et RL (ch1)

Une seule réactance : pente ±20 dB/décade.

11er ordre

Passe-bas RC

  • \[ \underline H = \dfrac{1}{1+jRC\omega} \]
  • \[ \omega_c = \dfrac{1}{RC}\ ,\quad f_c = \dfrac{1}{2\pi RC} \]
  • sortie aux bornes de C ; H0 = 1 ; phase de 0 à −90°
21er ordre

Passe-haut RC

  • \[ \underline H = \dfrac{jRC\omega}{1+jRC\omega} \]
  • \[ f_c = \dfrac{1}{2\pi RC} \]
  • sortie aux bornes de R ; phase de +90° à 0
31er ordre

Passe-bas RL

  • \[ \underline H = \dfrac{R}{R+jL\omega} = \dfrac{1}{1+jL\omega/R} \]
  • \[ \omega_c = \dfrac{R}{L}\ ,\quad f_c = \dfrac{R}{2\pi L} \]
  • sortie aux bornes de R
41er ordre

Passe-haut RL

  • \[ \underline H = \dfrac{jL\omega}{R+jL\omega} \]
  • \[ f_c = \dfrac{R}{2\pi L} \]
  • sortie aux bornes de L

2. Filtres du 2e ordre RLC (ch1, TP1)

x = ω/ω0 ; pour une chaîne RLC série : ω0 = 1/√(LC) et Q = (1/R)√(L/C).

52e ordre RLC série

Passe-bande RLC série (sortie aux bornes de R)

  • \[ \underline H = \dfrac{1}{1+jQ\left(x-\dfrac{1}{x}\right)} \]
  • \[ \omega_0 = \dfrac{1}{\sqrt{LC}}\ ,\quad Q = \dfrac{1}{R}\sqrt{\dfrac{L}{C}} \]
  • \[ \Delta\omega = \dfrac{\omega_0}{Q} \]
  • H0 = 1 à f0 ; phase nulle à f0
62e ordre RLC série

Passe-bas RLC série (sortie aux bornes de C)

  • \[ \underline H = \dfrac{1}{1+j\dfrac{x}{Q}-x^2} \]
  • \[ |\underline H(\omega_0)| = Q\ ,\quad \text{phase}(\omega_0) = -90^\circ \]
  • \[ \text{résonance si } Q>\dfrac{1}{\sqrt2}\ :\ \omega_r = \omega_0\sqrt{1-\dfrac{1}{2Q^2}} \]
  • pente −40 dB/décade
72e ordre RLC série

Passe-haut RLC série (sortie aux bornes de L)

  • \[ \underline H = \dfrac{-x^2}{1+j\dfrac{x}{Q}-x^2} = \dfrac{jQx}{1+jQ\left(x-\dfrac1x\right)} \]
  • \[ |\underline H(\omega_0)| = Q \]
  • pente +40 dB/décade ; H → 1 à haute fréquence
82e ordre RLC

Passe-bande « bouchon » (R série + L ∥ C)

  • \[ \underline H = \dfrac{1}{1+jQ'\left(x-\dfrac1x\right)} \]
  • \[ Q' = R\sqrt{\dfrac{C}{L}}\ ,\quad \omega_0 = \dfrac{1}{\sqrt{LC}} \]
  • sortie aux bornes du parallèle L ∥ C ; attention : Q' = R√(C/L), pas (1/R)√(L/C)
92e ordre RC

Pont de Wien (passe-bande RC)

  • \[ \underline H = \dfrac{1/3}{1+\dfrac{j}{3}\left(\dfrac{\omega}{\omega_0}-\dfrac{\omega_0}{\omega}\right)} \]
  • \[ \omega_0 = \dfrac{1}{RC}\ ,\quad H_0 = \dfrac13 \]
  • phase nulle à ω0 ; gain maximal 1/3 (pas de résonance)
