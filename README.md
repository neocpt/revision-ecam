# Révision ECAM

Site de révision pour les deux premières années de l'ECAM : résumés de cours, exercices corrigés, corrections de TD et annales.

**Voir le site : https://neocpt.github.io/revision-ecam/**

## Contenu

- **1ʳᵉ année** : Physique-Chimie, Mathématiques (M01 et M02), Sciences de l'Ingénieur (SII)
- **2ᵉ année (AM2)** : Physique-Chimie (électronique), Mathématiques, Sciences de l'Ingénieur (SI)
- **Annales** : DS, interrogations et partiels
- **Corrections exo** : corrigés des TD de SI (accès par code)

## Structure du dépôt

| Dossier | Rôle |
|---|---|
| `index.html` | Page d'accueil |
| `physique-chimie/`, `maths/`, `sii/`, `aem2-*/` | Une page par chapitre |
| `annales/` | Annales, classées par année |
| `corrections-exo/` | Corrections des TD de SI |
| `documents/` | PDF originaux (cours, TD, corrigés) auxquels renvoient les pages |
| `assets/` | Feuille de style et visionneuse PDF |

## Utilisation hors ligne

Télécharger le dépôt (bouton **Code** > **Download ZIP**), puis ouvrir `index.html`. Garder tous les dossiers ensemble, sinon les liens et les PDF ne s'affichent pas.

## Accès

Le site est protégé par un mot de passe ; les pages de corrections demandent un code. Pour un accès, contacter l'auteur.
