Géométrie de l'espace

1. Résumé de cours détaillé

Espace euclidien muni d'un repère orthonormé direct \(\mathfrak R(O,\vec\imath,\vec\jmath,\vec k)\). Point \(M(x,y,z)\) tel que \(\vec{OM}=x\vec\imath+y\vec\jmath+z\vec k\).

1.1 Coordonnées : cartésiennes ↔ cylindriques

Cylindriques \((r,\theta,z)\) \(\begin{cases}x=r\cos\theta\\ y=r\sin\theta\\ z=z\end{cases}\) avec \(r=\sqrt{x^2+y^2}\geqslant0\) (distance à l'axe \(Oz\)), \(\theta\) angle dans le plan horizontal (attention au quadrant), \(z\) la hauteur.

Distance : \(AB=\sqrt{(x_B-x_A)^2+(y_B-y_A)^2+(z_B-z_A)^2}\) ; norme \(\|\vec u\|=\sqrt{x^2+y^2+z^2}\).

1.2 Produit scalaire

Expression & angle \(\vec u\cdot\vec v=xx'+yy'+zz'=\|\vec u\|\,\|\vec v\|\cos\theta\), avec \(\theta=(\vec u,\vec v)\in[0,\pi]\) (dans l'espace l'angle n'est pas orienté). Orthogonalité : \(\vec u\perp\vec v\iff\vec u\cdot\vec v=0\).

1.3 Produit vectoriel

Définition Pour \(\vec u=(x,y,z)\), \(\vec v=(x',y',z')\) en base orthonormée directe : \[ \vec u\wedge\vec v=\big(yz'-zy',\ zx'-xz',\ xy'-yx'\big). \] Il est orthogonal à \(\vec u\) et \(\vec v\), antisymétrique (\(\vec v\wedge\vec u=-\vec u\wedge\vec v\)), bilinéaire.
À quoi ça sert • \(\vec u\wedge\vec v=\vec 0\iff\vec u,\vec v\) colinéaires (points \(A,B,C\) alignés ⟺ \(\vec{AB}\wedge\vec{AC}=\vec 0\)).
• Identité de Lagrange : \(\|\vec u\wedge\vec v\|=\|\vec u\|\,\|\vec v\|\sin(\vec u,\vec v)\).
• Aire du triangle \(=\tfrac12\|\vec{AB}\wedge\vec{AC}\|\) ; du parallélogramme \(=\|\vec u\wedge\vec v\|\).
• Vecteur normal à un plan : \(\vec n=\vec u\wedge\vec v\).

1.4 Produit mixte (déterminant 3×3)

Définition \([\vec u,\vec v,\vec w]=(\vec u\wedge\vec v)\cdot\vec w=\det(\vec u,\vec v,\vec w)= \begin{vmatrix}x&x'&x''\\ y&y'&y''\\ z&z'&z''\end{vmatrix}\) (règle de Sarrus). Antisymétrique (change de signe par échange de deux vecteurs), invariant par permutation circulaire, alterné (nul si deux vecteurs égaux).
Interprétations Volume du parallélépipède \(=\big|[\vec u,\vec v,\vec w]\big|\) ; du tétraèdre \(=\tfrac16\big|[\vec{AB},\vec{AC},\vec{AD}]\big|\). Coplanarité : \(\vec u,\vec v,\vec w\) coplanaires ⟺ \([\vec u,\vec v,\vec w]=0\).

1.5 Plans

Deux représentations Paramétrique (point \(A\), deux directeurs non colinéaires \(\vec u,\vec v\)) : \((x,y,z)=A+\alpha\vec u+\beta\vec v\).
Cartésienne : \(ax+by+cz+d=0\) avec vecteur normal \(\vec n=(a,b,c)\). Passage : \(\vec n=\vec u\wedge\vec v\), puis \(a(x-x_A)+b(y-y_A)+c(z-z_A)=0\).
Positions Deux plans sont parallèles ⟺ leurs normales sont proportionnelles ; confondus ⟺ \((a,b,c,d)\) proportionnels. Un plan « perpendiculaire à une droite » a pour normale le vecteur directeur de la droite.

1.6 Droites

Paramétrique & intersection de plans \(D=A+\operatorname{Vect}(\vec u)\) : \((x,y,z)=A+t\vec u\). Toute droite s'écrit comme intersection de deux plans \(\{P_1,P_2\}\) ; un directeur est alors \(\vec u=\vec n_1\wedge\vec n_2\). Deux droites sont sécantes si le système de leurs paramétrages admet une solution ; parallèles si \(\vec u_1\parallel\vec u_2\).

1.7 Distances

Trois formules clés Point–plan \(P:ax+by+cz+d=0\) : \(\displaystyle d(M,P)=\frac{|ax_M+by_M+cz_M+d|}{\sqrt{a^2+b^2+c^2}}\).
Point–droite \(D=A+\operatorname{Vect}(\vec u)\) : \(\displaystyle d(M,D)=\frac{\|\vec{AM}\wedge\vec u\|}{\|\vec u\|}\).
Droite–droite (non parallèles) : \(\displaystyle d(D,D')=\frac{\big|[\vec u,\vec u',\vec{MM'}]\big|}{\|\vec u\wedge\vec u'\|}\) (volume ÷ aire de base = hauteur).
Projeté orthogonal de \(M\) sur \(D=A+\operatorname{Vect}(\vec u)\) \(H=A+\dfrac{\vec{AM}\cdot\vec u}{\|\vec u\|^2}\,\vec u\) (unique point de \(D\) tel que \(\vec{HM}\cdot\vec u=0\)).

1.8 Sphères

Équation \((x-a)^2+(y-b)^2+(z-c)^2=R^2\), soit \(x^2+y^2+z^2-2ax-2by-2cz+(a^2+b^2+c^2-R^2)=0\) (compléter les carrés).
Intersections avec un plan \(P\) / une droite \(D\) On compare \(d(\Omega,\cdot)\) à \(R\). Plan : \(>R\) : \(\varnothing\) ; \(=R\) : tangent (1 point) ; \(cercle de centre \(H\) (projeté de \(\Omega\)) et rayon \(\sqrt{R^2-d^2}\). Droite : 0, 1 (tangente) ou 2 points.

Exercice 7 — Équations de plans (5 cas)♦♦♦

1) \(A(1,0,1)\), normal \(\vec n(1,-1,2)\)

Cartésienne : \(1(x-1)-1\cdot y+2(z-1)=0\Rightarrow x-y+2z-3=0\). Directeurs \(\perp\vec n\) : \(\vec u(1,1,0),\vec v(2,0,-1)\).

\(x-y+2z-3=0\) ; \(\{x=1+\alpha+2\beta,\ y=\alpha,\ z=1-\beta\}\)

2) \(A(0,1,1)\), engendré par \(\vec u(1,-1,0),\ \vec v(0,0,2)\)

Normale \(\vec u\wedge\vec v=(-2,-2,0)\propto(1,1,0)\). Cartésienne : \(x+(y-1)=0\Rightarrow x+y-1=0\).

\(x+y-1=0\) ; \(\{x=\alpha,\ y=1-\alpha,\ z=1+2\beta\}\)

3) \(A(1,-1,0)\), parallèle à \(\mathfrak D:x-2z+1=0\)

Même normale \((1,0,-2)\) : \((x-1)-2z=0\Rightarrow x-2z-1=0\).

\(x-2z-1=0\) ; \(\{x=1+2\beta,\ y=-1+\alpha,\ z=\beta\}\)

4) \(A(1,-1,1)\), perpendiculaire à \(D:\{2x-y+1=0,\ x-y+z-2=0\}\)

Le plan a pour normale le directeur de \(D\) : \(\vec n_1\wedge\vec n_2\) avec \(\vec n_1(2,-1,0),\vec n_2(1,-1,1)\) : \((-1,-2,-1)\propto(1,2,1)\). Cartésienne : \((x-1)+2(y+1)+(z-1)=0\Rightarrow x+2y+z=0\).

\(x+2y+z=0\) ; \(\{x=1+2\alpha+\beta,\ y=-1-\alpha,\ z=1-\beta\}\)

5) \(A(1,0,1)\), \(B(0,1,-1)\), \(C(2,1,0)\)

\(\vec{AB}=(-1,1,-2)\), \(\vec{AC}=(1,1,-1)\), \(\vec{AB}\wedge\vec{AC}=(1,-3,-2)\). Cartésienne : \((x-1)-3y-2(z-1)=0\Rightarrow x-3y-2z+1=0\) (contrôle \(B,C\) ✓).

\(x-3y-2z+1=0\) ; \(\{x=1-\alpha+\beta,\ y=\alpha+\beta,\ z=1-2\alpha-\beta\}\)

Exercice 10 — Trois plans : \(AX=B\), \(\det A\), \(A^{-1}\)♦♦♦
\(\{x+y+z=3,\ 2x-y+z=1,\ x+2y-3z=0\}\).

Intersection unique : \(\big(\tfrac8{13},\tfrac{17}{13},\tfrac{14}{13}\big)\)

Contrôle : \(2\cdot\tfrac8{13}-\tfrac{17}{13}+\tfrac{14}{13}=\tfrac{13}{13}=1\) ✓.

Exercice 15 — Intersection plan ∩ sphère♦♦♦

1) \(x+y+z=3\) et \(x^2+y^2+z^2=5\)

Sphère centre \(O\), \(R=\sqrt5\). \(d(O,\text{plan})=\dfrac3{\sqrt3}=\sqrt3<\sqrt5\) : cercle. Rayon \(\sqrt{R^2-d^2}=\sqrt{5-3}=\sqrt2\), centre \(H=(1,1,1)\) (projeté de \(O\)).

Cercle de centre \((1,1,1)\), rayon \(\sqrt2\), dans le plan \(x+y+z=3\)

2) \(x+y+z=2\) et \(x^2+y^2+z^2-4x-2z-20=0\)

Sphère centre \(\Omega(2,0,1)\), \(R^2=4+0+1+20=25\), \(R=5\). \(d(\Omega,\text{plan})=\dfrac{|2+0+1-2|}{\sqrt3}=\dfrac1{\sqrt3}<5\) : cercle. \(H=\Omega+\dfrac{2-3}3(1,1,1)=\big(\tfrac53,-\tfrac13,\tfrac23\big)\), rayon \(\sqrt{25-\tfrac13}=\sqrt{\tfrac{74}3}\).

Exercice 16 — Distance droite–sphère♦♦♦
\(D:\{x-y+z=0,\ x+z=1\}\) ; \(S:x^2+y^2+z^2-6x+2y-4z=-5\).

Sphère : centre \(\Omega(3,-1,2)\), \(R^2=9+1+4-5=9\), \(R=3\).

Directeur de \(D\) : \(\vec u=\vec n_1\wedge\vec n_2=(-1,0,1)\) (\(\vec n_1(1,-1,1),\vec n_2(1,0,1)\)). Point \(A_0(0,1,1)\in D\).

\(\vec{A_0\Omega}=(3,-2,1)\), \(\vec{A_0\Omega}\wedge\vec u=(-2,-4,-2)\), \(\|\cdot\|=\sqrt{24}=2\sqrt6\), \(\|\vec u\|=\sqrt2\). \(d(\Omega,D)=\dfrac{2\sqrt6}{\sqrt2}=2\sqrt3\approx3{,}46\).

Comme \(d(\Omega,D)=2\sqrt3>R=3\), la droite est extérieure à la sphère : distance \(=d(\Omega,D)-R\).

\(d(D,S)=2\sqrt3-3\approx0{,}46\)
